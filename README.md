# Магазин техники

Небольшой проект на React с карточками товаров.

В магазине представлены беспроводные наушники, механическая клавиатура и игровая мышь.

Карточки показывают изображение, название и цену товара. Кнопка «Добавить в корзину» позволяет увеличивать количество выбранных товаров.

## Запуск проекта

```bash
npm install
npm run dev
```
